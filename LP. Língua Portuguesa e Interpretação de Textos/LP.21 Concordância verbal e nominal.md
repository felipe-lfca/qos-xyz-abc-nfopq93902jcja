## Resumo do tópico

Concordância é a harmonia de gênero, número e pessoa entre os termos. A PMMG cobra os **casos especiais**, não *o menino chegou*.

### Concordância nominal — #Q2013-07

| Palavra | Comportamento | Exemplo certo |
| :---- | :---- | :---- |
| **alerta** | invariável como predicativo/adjetivo adverbializado | *Os alunos ficaram **alerta*** |
| **meio** | advérbio (= um pouco) invariável; adjetivo (= metade) varia | *porta **meio** aberta*; *meia hora* |
| **menos, anexo, incluso, quite, obrigado** | *menos* invariável; *anexo/incluso/quite/obrigado* variam | *seguem **anexas** as cópias*; *obrigada* (mulher) |
| **é proibido / é necessário / é bom** | invariáveis **sem** artigo; variam **com** determinante | *É proibido entrada*; *É **proibida a** entrada* |
| **só** | adjetivo varia (*sós*); advérbio não | *Eles ficaram sós* / *só eles vieram* |
| **mesmo, próprio** | variam | *elas **mesmas*** |

Gabarito: *ficaram alerta* + *meio aberta*. *Alertas* e *meia aberta* estão errados nesse sentido.

### Concordância verbal — #Q2023-09

Julgar V/F:

1. *foi preso muitos suspeitos* — **F**. Sujeito *muitos suspeitos* (plural, posposto): *foram presos muitos suspeitos*.
2. *O comerciante que distribuía… sempre foram muito generosos* — **F**. Núcleo *comerciante* (sing.) puxa *foi / era*. O *que* relativo não pluraliza o verbo da principal.
3. *Os oitenta por cento que ajudaram… participaram* — **V**. Percentual com determinante plural (*os*) e relativo no plural: verbo no plural.
4. *Haviam trinta pessoas* — **F**. *Haver* existencial é **impessoal**: *Havia trinta pessoas*.

Sequência: F, F, V, F.

### *Haver* e *fazer* impessoais — #Q2024-06

- Existir / ocorrer / tempo decorrido: *Há teorias*; *Faz anos*; **não** *haverão teorias*, **não** *fazem anos*.
- *Haver* auxiliar concorda: *Os alunos **haviam** estudado*.
- *Existir, ocorrer, restar, faltar* são pessoais: *Existem teorias*; *faltam dois dias*.

### Outros casos de prova

- **Partícula *se*** apassivadora: verbo concorda com o sujeito paciente — *Vendem-se casas*; *Aluga-se quarto*.
- **Índice de indeterminação** (*se* com VI/VTI/VL): verbo na 3ª do singular — *Precisa-se de técnicos*; *Vive-se bem*.
- **Sujeito composto** depois do verbo: concorda com o mais próximo ou com o plural (as duas aceitas; o plural é mais seguro em prova).
- **Um dos que**: *foi um dos que **chegaram*** (preferência pelo plural).
- **Percentual**: *1% da turma **chegou***; *80% dos alunos **chegaram***; com artigo plural (*os 80%*) → plural.
- **Nomes de instituição / títulos**: *Os Lusíadas é* (obra) / *são* (se se destaca o plural do título — prefira o singular com artigo *Os Lusíadas **é***).
- **Pronome de tratamento**: 3ª pessoa.

## Cobertura extra — casos ainda não cobrados

### Concordância verbal — o resto do edital

| Estrutura | Norma de prova |
| :---- | :---- |
| *A maioria dos alunos* | singular (ideia de conjunto) ou plural (ideia dos indivíduos) — as duas; plural é mais “seguro” se vier *dos alunos* |
| *Cerca de / mais de / menos de + plural* | plural: *Cerca de vinte chegaram* |
| *Mais de um* | singular: *Mais de um médico faltou* (recíproco: plural *mais de um se cumprimentaram*) |
| *Um e outro / nem um nem outro* | singular ou plural; *nem um nem outro faltou* comum no singular |
| *Quais de nós / quais de vós* | 3ª plural ou a pessoa do pronome: *Quais de nós faltamos / faltaram* |
| *Quem* (sujeito) | 3ª singular: *Fui eu quem resolveu* (tradicional) |
| *Que* relativo | concorda com o antecedente: *Fui eu que resolvi* |
| Sujeito oracional | 3ª singular: *Ainda falta pagarem as contas* (discutido) / *É preciso que venham* |
| Coletivo + *de* + plural | *A turma de alunos chegou* (núcleo *turma*) ou *chegaram* (atracão) |
| *Haja vista* | locução: *haja vista os fatos* (invariável na forma clássica) ou *hajam vista os fatos* (alguns) — prefira *haja vista* invariável |
| *Os Estados Unidos / as Nações Unidas* | plural com artigo: *Os EUA são* |
| Silepse | *Vossa Excelência está cansado*; *A gente fomos* (esta última é coloquial — a prova pune) |

### Concordância nominal extra

- Adjetivo após dois substantivos: concorda com o mais próximo *ou* vai ao plural masculino se houver os dois gêneros (*estudo e prática **necessários***).
- Adjetivo anteposto: em geral com o mais próximo (*boa prática e estudo*).
- *É bom / é necessário / é proibido* sem determinante invariável; com *a/o* varia.
- *Menos* nunca varia (*menos alunas*, não *menas*).
- *Anexo, incluso, quite, obrigado, leso* variam. *Em anexo* é locução invariável.
- *Possível* em *o mais… possível*: *as melhores notas **possível*** (clássico) ou *possíveis* (moderno). Prova tradicional: *possível* invariável com *o mais / o menos*.

## Pontos-chave

- #Q2013-07 · #Q2023-09
- *Alerta* invariável; *meio* + adjetivo invariável.
- *Haver* existencial = singular sempre (*há / havia / haverá*).
- Passiva com *se*: o verbo concorda com o substantivo (*vendem-se casas*).
- Relativo *que*: o verbo da adjetiva concorda com o **antecedente**.
- *Foi preso muitos* é erro grosseiro de número e de gênero/número do particípio.
